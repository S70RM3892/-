# 京大工学部 情報学科 受験分析（令和9年度 / 2027年2月25・26日）

公開情報から、合格最低点の構造・第2志望の価値・共通テストと二次試験の
得点配分を推定する。**主張ごとに「一次資料 / 推定 / 個人の仮定」を明示する**
ことを設計上の第一原則にしている。

```bash
./run_all.sh          # 全解析を実行し outputs/ に保存（標準ライブラリのみ）
python3 -m pytest tests/ -q   # 43件の検証（pytest が要る）
```

## 2. 情報学科の合格最低点は「突出して不安定」なのか **[推定]**

→ `analysis/p01_panel.py`

旧版はこれを主要な発見として掲げていた（残差SD 1.04pt、F=4.45、p=0.0041）。
5通りの切り方で検証した結果、**この主張は標本の取り方に強く依存する**。

| 標本 | 情報の残差SD | F | 並べ替え p |
|---|---|---|---|
| 全8年 2019–2026 | 1.037pt (10.6点) | 4.45 | 0.0042 |
| 2024年を除く7年 | 0.703pt (7.2点) | 1.96 | 0.035 |
| **旧配点のみ 2019–2024** | **0.431pt (4.4点)** | **0.68** | **0.71** |
| 新配点のみ 2025–2026 | 推定不能（n=2、トレンド除去後 df=0） | — | — |

さらに、`dv_t = a + b·t + c·1[t≥2025] + e_t` を当てると:

| 学科 | 段差 c | 段差除去前SD | 除去後SD | 段差が説明する分散 |
|---|---|---|---|---|
| **情報** | **−2.77pt (−28.4点)** | 1.037 | **0.554** | **71.5%** |
| 物理工 | +1.06 | 0.463 | 0.337 | 47.2% |
| 電電 | +0.60 | 0.473 | 0.472 | 0.5% |
| 建築 | +0.03 | 0.730 | 0.799 | — |
| 地球工 | +0.25 | 0.252 | 0.260 | — |
| 理工化 | +0.83 | 0.415 | 0.346 | 30.8% |

情報だけが大きな**負**の段差を持ち、その残差分散の 71.5% が段差で説明できる。

さらに、旧版の並べ替え検定は6学科を交換可能と仮定していたが、
情報は合格率が最も低く順序統計量の標本変動がもともと大きい。
学科ごとの期待標本SDで標準化した帰無を使うと p は 0.0042 → 0.0057 になる。

**結論の書き換え:**

> 情報学科は「毎年ランダムに大きくブレる学科」ではなく、
> **「2025年の配点改定の影響を最も強く受けた学科であり、新配点下の分散は
> まだ測れていない（n=2）」** と言うのが、データが支持する最大の主張である。

旧版の「σ=10.6点」を定常ノイズとして下流で使うのは過大。段差を除けば 5.7点。
以降は **5.7–10.6点の帯**で扱う。

## 3. 第2志望をどう選ぶか **[推定]** ＋ **[仮定]**

→ `analysis/p02_gap_ladder.py`

### 3.1 一方向仮説（定理ではない）

c を第1志望として落ち d に第2志望で受かった人は 得点 < cutoff_c かつ 得点 ≥ cutoff_d。
よって cutoff_c > cutoff_d。流入は最低点の高い学科から低い学科へしか起こらない。

**この導出は「学部全体を1本の点数順に並べ、各学科の定員まで順に取る」
（serial dictatorship）を仮定している。** §1 の通り募集要項にその記述はない。
旧版はこれを「確定している制度事実」の節に置いていた。**作業仮説に格下げする。**

仮説が正しければ、情報学科は 2019–2026 の8年すべてで最低点1位なので
第2志望流入はゼロ、定員は100%が第1志望者になる。

### 3.2 旧版の確率計算は式が誤っていた

旧 `sd7.py` は分母を `sqrt(sp² + σ_情報² + SD(gap)²)` としていた。しかし

```
T + gap = (得点 − cutoff_情報) + (cutoff_情報 − cutoff_相手) = 得点 − cutoff_相手
```

なので **cutoff_情報 は完全に相殺される**。正しい分散は `sp² + Var(cutoff_相手)` だけ。
旧版はギャップのSD（その 67–95% は情報自身の変動）をそのまま足していた。

| 第2志望 | 最低点由来のノイズ（旧版） | 正しい値 | 倍率 |
|---|---|---|---|
| 物理工 | 18.1点 | 4.8点 | 3.8× |
| 電電 | 16.7 | 4.8 | 3.4× |
| 建築 | 18.2 | 7.5 | 2.4× |
| 地球工 | 16.0 | 2.6 | 6.2× |
| 理工化 | 16.5 | 4.3 | 3.9× |

ただし正直に言うと、**最終確率への影響は +0.1〜+2.9 ポイント**にとどまる。
個人の当日ゆらぎ `sp` が分母を支配するからである。式は誤りだが結論は動かない。

### 3.3 確率表は個人パラメータの関数である **[仮定]**

旧版は `sT=65.4; muT=-0.553*sT` を行内にハードコードし、出典が追えなかった。
しかも README 末尾には「ユーザー自身の模試成績は本分析の結論には使っていない」
と書かれていた。**この2つは明らかに個人の得点分布パラメータで、記述が矛盾していた。**

mu（自分の実力 − 情報の合格最低点）を振ると、表はこれだけ動く
（sp=64.5点、ギャップは8年平均）:

| mu | 物理工 | 電電 | 建築 | 地球工 | 理工化 | 第2志望なし |
|---|---|---|---|---|---|---|
| −80点 | 27% | 33% | 35% | 45% | 49% | 11% |
| −36点 | 53% | 60% | 62% | 71% | 74% | 29% |
| 0点 | 74% | 79% | 80% | 87% | 89% | 50% |
| +20点 | 83% | 87% | 88% | 92% | 94% | 62% |

旧 README の「53.0%」のような 0.1% 刻みの表示は、**存在しない精度の偽装**だった。

なお `sp=64.5点` は志願者プール全体の得点SD（約73.8点）の 87% にあたり、
個人の当日ゆらぎとしては大きすぎる可能性が高い。`params.json` で 30/45/64.5/80 を振る。

### 3.4 この表から読み取ってよいこと

**mu, sp, σ をどう置いても順序は変わらない:**

> 理工化 > 地球工 > 建築 > 電電 > 物理工

これは平均ギャップの順序そのもの、つまり **「最低点が最も低い学科を書け」** に等しい。
志願倍率で選ぶのは誤り（建築は倍率2.12位に対し最低点3.62位）。
自分の第1志望より最低点が高い学科を書いても、§3.1 の仮説の下では無効。

**個々のセルの確率の絶対値は読み取ってはいけない。**

## 5. 共テで京大工レベルが落としている点 **[推定]**

→ `analysis/p05_irt_ct.py`

設問別得点状況に、全設問共通のディスクリミネーション r を持つ正規オジャイブ模型を当てる。
r は模型の総得点SDが公表SDに一致するよう較正する。

### 5.1 まず、旧版の最大の問題から

**能力水準 z=+2.0 に根拠が無かった。** そして結論は z に極端に敏感である:

| z | 全国上位 | 共テ得点率 | 取りこぼし合計 |
|---|---|---|---|
| +1.50 | 6.68% | 82.8% | 34.3点 |
| **+1.69** | 4.55% | **85.0%（河合塾ボーダー）** | **30.0点** |
| +1.98 | 2.39% | 88.0% | 24.0点 |
| +2.00 | 2.28% | 88.2% | 23.7点（旧版の決め打ち） |
| +2.50 | 0.62% | 92.1% | 15.7点 |
| +3.00 | 0.13% | 94.9% | 10.1点 |

旧 README が示していた不確実性（模型 23.7 vs 公表分位点 16.6）より、
**z の選び方による幅の方がはるかに大きい**。公表ボーダー 85% に合わせると
30.0点になり、旧版のバンドの外に出る。

### 5.2 さらに重要な注意: 合計値は推定量ではない

z を「共テ得点率 85%」に合わせた時点で、取りこぼし合計は 200 × 15% = 30.0点 と
**算術的に決まる**。模型が実際に推定しているのは合計ではなく、
**その30点が科目間・設問間にどう配分されるか**だけである。
旧 README が「合計16.6–23.7点」を主要な結果として前面に出していたのは、
推定でないものを推定として提示していたことになる。

### 5.3 科目別の配分（4つの方法）

| 科目 | A:旧z=2 | B:ボーダー | C:rho=0.2 | D:公表分位 | 帯 |
|---|---|---|---|---|---|
| **情報Ⅰ** | 8.4 | 10.0 | 11.3 | 6.0 | **6.0–11.3** |
| 地歴公民 | 4.7 | 6.1 | 5.9 | 3.0 | 3.0–6.1 |
| 英語L | 3.7 | 4.5 | 4.4 | 2.5 | 2.5–4.5 |
| 物理 | 2.4 | 2.9 | 2.9 | 1.9 | 1.9–2.9 |
| 数学ⅠA | 2.1 | 2.6 | 2.4 | 1.8 | 1.8–2.6 |
| 数学ⅡBC | 0.9 | 1.4 | 1.1 | 0.5 | 0.5–1.4 |
| 化学 | 0.8 | 1.2 | 1.0 | 0.5 | 0.5–1.2 |
| 英語R | 0.8 | 1.3 | 0.9 | 0.5 | 0.5–1.3 |
| **合計** | 23.7 | 30.0 | 30.0 | 16.6 | **16.6–30.0** |

C は同一大問内の残差相関 rho=0.2 を入れた版（局所独立の緩和）。

設問単位では、情報Ⅰの取りこぼしは上位10設問で 56%、大問別では
第1問 33% / 第2問 28% / 第3問 23% / 第4問 16%。

### 5.4 模型の当てはめ誤差が結論と同じ向きに効いている

| 科目 | 較正 r | p97.7 の過小評価 | 取りこぼし順位 |
|---|---|---|---|
| **情報Ⅰ** | **0.434（最低）** | **−4.8点（最大）** | **1位** |
| 英語L | 0.486 | −4.6 | 3位 |
| 地歴公民 | 0.469 | −3.4 | 2位 |
| 英語R | 0.643 | −1.1 | 7位 |

corr(r, 取りこぼし素点) = **−0.49**、corr(r, 上側の当てはめ誤差) = **−0.78**。
**模型の当てはまりが最も悪い科目が、そのまま結論の主役になっている。**

さらに解釈上の問題がある。r が低いとは「その科目の得点が学力と連動しない」
という意味である。模型自身が「情報Ⅰの得点は実力で説明しにくい」と言っているのに、
結論はそれを「だから情報Ⅰを詰めれば取り返せる」と読んでいる。
**逆の読み（低 r の失点＝勉強で回収しにくい運の部分）も同じデータと整合する。**
対抗仮説（初年度で誰も対策していなかったから r が低い、ゆえに対策の限界収穫は大きい）
も同様に整合する。**この模型では識別できない。**

r を全科目共通（0.553）に固定しても情報Ⅰが1位である点は変わらない（配点係数0.5が効く）。
**順位は頑健、量は頑健でない。**

## 7. 点あたりの時間 **[仮定]** ← 旧版に存在しなかった

→ `analysis/p07_budget.py`

旧版は一貫して「点がどこに残っているか」を測り、**「どこの点が安いか」を
一度も測っていなかった**。情報Ⅰの10点と物理の2.9点を並べても、
回収に要する時間が10倍違えば結論は逆になる。

この節の数字は**公開情報 0%・個人の仮定 100%** である。
それでも置くのは、費用の列を空欄にしておくと読み手が暗黙に費用を一定と
仮定してしまうからである。**空欄を可視化することが目的で、順位の確定ではない。**

損益分岐点（既定の仮定のもと）:

> 二次数学が 400時間で大問2単位ぶん伸びるなら、共テ情報Ⅰは **40時間以内**で
> 仕上がる場合にのみ割がよい。既定の見積もり（60時間）では二次数学が勝つ。

`params.json` の `study_cost` を自分の学習ログで置き換えるまで、
**この研究は勉強計画としては未完成である。**

## 8. 棄却・断念した仮説 **[推定]**

→ `analysis/p09_rejected.py` / `p08_ratio.py`（すべて実行可能なコードとして残した）

| 仮説 | 結果 |
|---|---|
| 隔年現象 | **棄却。** 実測のラグ1自己相関 −0.042 に対し、順序を壊した帰無でも −0.141。機械的な負値と見分けがつかない |
| 難易度→最低点の翻訳 | **不可能。** LOO MAE 4.76pt ＞ 「毎年平均を答える」MAE 4.47pt |
| 志願倍率が最低点を説明 | **between のみ。** プール r=+0.826 の内訳は between +0.891（学科6点）/ **within −0.178**（48観測）。倍率を足すと LOO MAE は 0.499 → 0.519 と**悪化**する |
| 需要のパススルーの減衰 | 検出力不足。学科ごとの within 傾きは符号すら揃わない（情報 −1.01、電電 +2.24、建築 −2.89） |
| 得点開示から科目間相関 | **不可能。** 工学部の有効件数は 4 |

### 旧版から取り下げた数値

## 10. 自分の得点の分散をどちらに動かすか **[推定]** ← この研究の一番の見落とし

→ `analysis/p12_risk.py`

不確実性の内訳を見ると:

| 項 | 大きさ |
|---|---|
| 合格最低点の年変動 σ | 5.7–10.6点 |
| **自分の当日ゆらぎ sp** | **30–80点** |

**全分散のうち相手側が占めるのは 1.7–11.2%。**
8年パネルで精密に推定してきたのは、小さい方の項でした。
前回「戦略分析から新しいものが出なかった」のは当然で、大きい項を一度も見ていない。

### 結果

`P = Φ(μ/s)` を s で微分すると `∂P/∂s = −φ(μ/s)·μ/s²`。符号が μ で反転します。

> **合格ラインより下にいる人は、本番の得点の分散を上げるべきである。
> 上にいる人だけが、分散を下げるべきである。**

分岐は実力の絶対水準ではなく、**ラインとの位置関係**で決まります。

| μ（実力−最低点） | sp=30 | sp=45 | sp=64.5 | sp=80 | 最適方向 |
|---|---|---|---|---|---|
| −60点 | 3.0% | 9.7% | 17.9% | 22.9% | **分散を上げる** |
| −36点 | 12.8% | 21.7% | 29.0% | 32.7% | **分散を上げる** |
| 0点 | 50.0% | 50.0% | 50.0% | 50.0% | 無関係 |
| +40点 | 89.6% | 80.7% | 73.0% | 69.0% | **分散を下げる** |

μ=−36点 の人が sp を 64.5 → 45 に下げると、合格確率は **7.3ポイント下がります**。
「ミスを減らして安定させる」はこの位置では逆効果です。

### 交換レート

現実の戦略は分散だけを動かせません（難問に時間を賭ければ確実な点を失う）。
`dP > 0 ⟺ dμ > (μ/s)·ds` から:

> **許容できる期待値の損失 = |z| × 分散の増加分**（|z| = ラインから何σ下にいるか）

μ=−36点の人が得点SDを +20点 増やす戦略を取るなら、**期待得点が11点下がるところまでは
その戦略の方が合格確率が高い。**

京大二次は数学6問200点・1問30–40点（1025換算で37.5–50点）で、
**部分点と完答の差がそのまま大きな分散**になります。共テは設問が細かく部分点も無いので
分散を操作する余地が小さい。**この節はほぼ二次試験の話です。**

### なぜ見落とされていたか

- **生存者バイアスが助言の向きを歪めている。** 受験の助言は合格者から抽出されるが、
  合格者は定義上 μ>0 の人。だから「ミスをなくせ・確実に取れ」に偏る。
- **分散は事後的に観測できない。** 1回しか受けないので本人にも分からない。
- この研究自身が、相手側の分散を8年かけて精密に測り、自分側は出典不明の定数1個で
  済ませていた。

### この結果が使える理由

μ も sp も `status=USER` です。しかし**結論の向きを決めるのは μ の符号だけ**で、
符号（ラインの上か下か）は大きさよりはるかに推定しやすい。
**最も不確かな量に対して頑健**である点で、この研究で唯一まともに使える結果です。

## 11. 二次数学 150分6問 — 何問に手をつけるか **[仮定]** ＋ **[推定]**

→ `analysis/p13_exam_strategy.py`

§10 で「ラインより下なら分散を上げろ」という向きが出ましたが、実行するには
(期待値, 分散) の実現可能な組合せが要ります。公開データには存在しません。

ただし**京大数学は大問別配点が問題用紙に印刷される**ので、開始時点で配点が既知です。
時間配分の選択問題として定式化すれば、模型からフロンティアの形が出ます。

### 前提の実測（主張ではなく測った）

`data/ds.json` の大問別難易度評価（1990–2008, 19年×6問）:

| | |
|---|---|
| 年内の（最大−最小）の平均 | 1.58 |
| 6問が全部同じ評価だった年 | 1 / 19年 |
| 難易度の分散：**年内(問題間)** | **0.373** |
| 難易度の分散：年間(年の当たり外れ) | 0.105 |

> **問題間のばらつきが、年ごとのばらつきの 3.5 倍ある。**

受験生が気にするのは「今年の数学は難化したか」ですが、同じ年の中の問題差の方が
3倍以上大きい。**年の当たり外れは選べないが、問題の取捨は選べる。効く方が選べる方にあります。**

（出典は個人のnote記事の主観評価で旧課程期のみ。向きの確認には使えるが水準の推定には使えない）

### 結果

| τ プロファイル | 期待値最大の k | k=6 は支配されるか |
|---|---|---|
| 一様 [75]×6 | 6 | いいえ |
| やや差 [60,65,70,80,90,100] | 5 | **はい** |
| 標準 [55,60,70,85,110,140] | 4 | **はい** |
| 差が大きい [40,50,70,100,150,200] | 4 | **はい** |
| 全部重い [120]×6 | 6 | いいえ |

> **6問に均等配分するのが劣るのは、問題の重さに差があるときだけ。**
> そして京大数学では差がある（上で測った通り）。

τ が一様なら全問に配るのが最適です。差があると、重い問題に置いた時間の限界収穫が
ほぼゼロなので、軽い方に寄せると**期待値も分散も改善**します。β（部分点の効き）を
0〜0.8 で振っても結論は変わりません。

### §10 の予想は外れました

p12 では「絞る = 分散を上げる」と暗に想定していましたが、**逆でした**。
2問に絞ると各問の完答確率が1に近づき `m²p(1−p)` は小さくなる。
**絞るのは期待値も分散も下げる方向**です。

したがって「μ<0 なら分散を買え」は、ここでは**「絞るな、広げろ」**になります。
§10 の向き自体は保たれていますが、それを実行する手段は直感と逆でした。

さらに正直に言うと、**μ 依存は小さい**。最適 k は μ が動いても 4 と 5 の間しか動きません。
支配的なのは水準効果（6問に散らすな、2問に籠るな）で、ラインとの距離による調整ではない。
**§10 の実務的な重みは、この模型の下では想定より小さいと下方修正します。**

### 副産物

模型は「どの問題が軽いか」を開始時点で知っていると仮定しています。現実には見極めに
時間がかかる。つまり k=4–5 の優位は上限値であり、同時に
**最初の十数分を全問の偵察に使う価値**を裏づけます。
偵察は期待値を直接生みませんが、k の選択を正しくすることで効きます。

## 限界（結論より先に読むこと）

1. **設問データは令和8年度の1年分のみ。** 年次変動は測れていない。
2. **全国分布は全受験者。** 京大工志願者の条件付き分布ではない。
3. **「取りこぼし」は満点との差であって、回収可能な点ではない。**
   回収コストは §7 で初めて入り、そこは全て個人の仮定である。
4. **新配点下のパネルは n=2。** 合格最低点の分散も、ギャップの水準も、
   新制度ではまだ2点しか観測がない。
5. **学科振り分けの機構は公開されていない。** §3 の一方向仮説は検証されていない。
6. §5 の科目順位は、模型の当てはめ誤差と同じ向きに歪んでいる可能性がある。
