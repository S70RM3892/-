# 京大工学部 情報学科 受験分析（令和9年度 / 2027年2月25・26日）

公開情報のみを一次資料から収集・検証した分析一式。出所は [SOURCES.md](SOURCES.md)。

各主張がどれだけ頑健かを `analysis/rb.py` で検証している。**結論を使う前にこれを読むこと。**

```bash
cd analysis && python3 rb.py
```

## 要約：どれを信じ、何に時間を使うか

| 主張 | 頑健さ | 行動に効くか |
|---|---|---|
| 共テ情報Ⅰ 1 点＝共テ数学 4 点（配点の実効価値） | **確実**（募集要項の割り算） | ◎ 最大 |
| 共テで残っている取りこぼしは情報Ⅰ・地歴公民に過半が集中 | **強い**（模型の較正法を変えても向きは不変） | ◎ |
| 第2志望は必ず書く。最低点の低い学科ほど効く（順序） | **強い**（serial dictatorship の帰結） | ◎ |
| 取りこぼしの合計点（16点 / 23.7点） | 弱い（較正基準と想定 z に依存） | △ 目安のみ |
| 第2志望ラダーの合格確率の**水準**（29%→74% 等） | **弱い**（出所不明の定数 2 個が決めている） | × 使わない |
| 情報学科の合格最低点だけが不安定 | **弱い**（2024 年 1 点に依存。絶対値では全学科同じ） | × 行動が変わらない |

**やるべきこと：共通テストの情報Ⅰと地歴公民を、二次の数学と同じ真剣さで詰める。
第2志望に理工化学科（または地球工学科）を書く。** それ以外は精度を上げても行動が変わらない。

## 確定している制度事実（令和9年度 募集要項 r9.pdf より座標抽出・検算済み）

| 区分 | 国語 | 地歴公民 | 数学 | 理科 | 外国語 | 情報 | 計 |
|---|---|---|---|---|---|---|---|
| 共通テスト | 25 | 50 | 25 | 25 | 50 | 50 | 225 |
| 個別学力検査 | 100 | — | 250 | 250 | 200 | — | 800 |
| 計 | 125 | 50 | 275 | 275 | 250 | 50 | 1025 |

- 二次素点 650（国語100 / 数学200 / 理科200 / 英語150）→ 工学部配点 800
  （国語×1.0 / 数学×1.25 / 理科×1.25 / 英語×1.333）
- 二次時間割: 2/25 国語 9:30–11:00 (90分) / 数学 13:30–16:00 (150分)
  　　　　　　 2/26 英語 9:30–11:30 (120分) / 理科 13:30–16:30 (180分)
- 大問別配点は問題用紙に印刷される（数学 30/35/40点）

  席が増えれば最低点は下がり、他学科との差は縮む。過去8年平均を令和9にそのまま使えない。

## 主要な分析結果

### 1. 第2志望の流れは一方向（定理）
c を第1志望として落ち d に第2志望で合格した人は、点数 < cutoff_c かつ 点数 ≥ cutoff_d。
よって **cutoff_c > cutoff_d**。流入は最低点の高い学科から低い学科へしか起こらない。

- 情報学科は 2019–2026 の8年すべてで最低点1位 → **流入ゼロ、定員は100%が第1志望者**
- 自分の第1志望より最低点が高い学科を第2志望に書いても物理的に無効
- 第2志望は志願倍率ではなく最低点で選ぶ（建築は倍率2.12位／最低点3.62位で乖離）

制度の帰結なので、データの精度に依存しない。この分析で最も硬い部分。

### 2. 情報学科の合格最低点の「不安定さ」は学部内の相対位置の話（要注意）
トレンド除去残差SD: 情報 1.04pt（=10.6点/1025）、他5学科プール 0.49pt。F = 4.45、
残差の学科ラベル並べ替え検定 p = 0.0041（Bonferroni×6 で 0.025）。

ただし `rb.py` が示す通り、この主張には 3 つの留保がある。

1. **絶対値では 6 学科とも横並び。** 学部平均からの乖離 `dv` ではなく素の得点率で同じ
   計算をすると、SD は 6 学科とも 4.1–4.5pt（≒43点/1025）で F = 0.97。合格最低点の
   年変動そのものは全学科共通の全国難易度ショックで、情報に固有なのは「学部平均から
   どれだけ離れるか」だけ。σ=10.6点 は**受験生自身の得点も学部平均と 1:1 で連動する**
   と仮定したときの実効ブレであり、絶対ブレはその 4 倍ある。
2. **2024年 1 点への依存。** 2024 を除くと F は 4.45 → 1.96、Bonferroni 後の p は
   0.025 → 0.21 で有意でなくなる。
3. **帰無の組み方で p が動く。** `sd4.py` が印字する p=0.9688 は「6学科の水準が全部同じ」
   という誰も信じていない帰無の下の値で、検定として意味がない（スクリプトに注記を入れた）。
   年構造を保存した正しい並べ替えでは p=0.0059 で `sd5.py` と整合する。

`dv` は構成上 6 学科でゼロ和なので、6 系列は独立標本ではない。F 検定の df=(6,30) は過大。
そしてこの結論が正しくても、受験生の行動は何も変わらない。

### 3. 第2志望ラダー（順序だけを使うこと）
| 第2志望 | 8年平均差 | 2026年のみ | 合格確率（参考値） |
|---|---|---|---|
| なし | — | — | 29.0% |
| 物理工 | 41.2点 | 30.2点 | 53.1% |
| 電電 | 52.4点 | 43.4点 | 59.9% |
| 建築 | 55.3点 | 49.2点 | 61.6% |
| 地球工 | 72.3点 | 64.3点 | 71.2% |
| 理工化 | 78.3点 | 64.4点 | 74.2% |

**確率の水準は信用してはいけない。** `sd7.py` の `sT=65.4点` と `muT=-0.553*sT`
（P(情報単願)=29.0% に相当）は一次資料から出てこない外生の仮定で、分散の 97.7% は
受験生自身の得点の側。P(情報単願) を 10%〜65% で動かすと理工化の値は 46.6%〜94.5% まで動く
（`rb.py` 5.）。動かないのは**順序**だけ。つまり「最低点の低い学科ほど良い」しか言えない。

- 情報学科の合格最低点の分散は `sT` の 2.3% しかない。第2志望の価値は
  「線が動くのをヘッジする」効果ではなく、単に自分の得点分布が広いことから来ている。
- `sd7.py` は SD に `sqrt(sT²+gapSD²)` を使っていたが、gap にも sT にも情報の最低点が
  入っており二重計上になる。正しくは `sqrt(Var(受験生)+Var(相手の最低点))`（影響は +0.1〜0.6pt）。
- 令和9は情報の席が 87→94 に増えている。差が縮む向きなので、8年平均差より
  「2026年のみ」列の方が近い。

### 4. 共通テストの実効配点 ← この分析で最も価値のある部分
1素点あたりの価値: 情報Ⅰ・地歴公民 0.50点 / 英語 0.25点 / 国語・数学・理科 0.125点。
**共テ情報Ⅰの1点＝共テ数学の4点。**

情報Ⅰの比重 22.2% は京大7学部で最大（経済16.7 / 理10.0 / 農8.6 / 医9.1 / 薬9.1 / 教育5.7）。
工学部だけが「二次で出る科目の共テを半額、出ない科目を定価」にしている（理学部はその真逆）。

全国上位10%→上位1% の価値（1025点換算、令和8/令和7）:
情報Ⅰ 7.0/4.0、地歴公民 4.0–4.5/4.5–6.0 に対し、
**数ⅠA+数ⅡBC+物理+化学の4科目合計が 6.9/6.8**。

上位10%層内の分散シェア: 情報Ⅰ+地歴公民 = 66.6%/62.2%（配点シェア44.4%）、
理系4科目 = 12.3%/14.6%（配点22.2%）。切断なしの全国SDでも 57.7%。

情報Ⅰは全国平均が 69.26（令和7）→ 56.59（令和8）と −12.7点。全科目中で最大の振れ。

ここは配点表の割り算と公表分布の集計だけで、モデルの仮定が入らない。

### 5. 共テで京大工レベルがまだ落としている点（設問単位）

大学入試センター公表の「設問別得点状況」(`data/q_r8.csv`) に、全設問共通の
ディスクリミネーション r を持つ正規オジャイブ模型を当てた。

**合計 16.6点（中心値）〜 23.7点（上限）**。README 旧版はこの 2 つを「模型」と
「公表分位点から直接」という別手法の上下限として並べていたが、`rb.py` 7. の通り
実際には**同じ模型を別の的に較正しただけ**である。単一の r では分布全体の SD と
上位裾を同時に再現できず、SD に合わせると r が小さくなりすぎて裾を外す。
上位 2.3% の議論をしたいなら裾で較正した側が筋なので、**採るべき中心値は 16 点台**。

全科目で全国上位2.3%(z=+2)相当の受験生が落としている点（1025点換算）:

| 科目 | 裾較正（採用） | SD較正（上限） |
|---|---|---|
| 情報Ⅰ | 6.0点 | 8.4点 |
| 地歴公民（政経） | 3.0 | 4.7 |
| 英語リスニング | 2.5 | 3.7 |
| 物理 | 1.9 | 2.4 |
| 数学ⅠA | 1.8 | 2.1 |
| 数学ⅡBC | 0.5 | 0.9 |
| 化学 | 0.5 | 0.8 |
| 英語リーディング | 0.5 | 0.8 |
| **合計** | **16.6** | **23.7** |

情報Ⅰ＋地歴公民が 54–55%、理系4科目（数ⅠA・数ⅡBC・物理・化学）は 26–28%。

設問単位では、情報Ⅰの取りこぼしは上位10設問で58%、大問別では
第1問34% / 第2問28% / 第3問22% / 第4問16%（令和8年度）。
理系科目の中では物理・数学ⅠAの取りこぼしが化学・数学ⅡBCの3–4倍。

**z=+2 は「どの科目でも全国上位2.3%」という受験生像で、京大工の実像ではない。**
二次800点が数学・理科・英語なのでその3科目に選抜がかかっており、実際は
数学理科で z が高く情報Ⅰ・地歴公民で低い。その向きに補正すると取りこぼしの
情報Ⅰ・地歴公民への集中は**さらに強まる**（合計は増える）。z=1.5/2.0/2.5 の表は `rb.py` 7.。
つまり科目の優先順位は頑健で、合計点の方が脆い。

設問データは令和8年度の1年分のみ。

### 6. 棄却・断念した仮説

再現コードは `analysis/rej.py`。**結論はすべて支持されるが、5 件中 2 件は
README に載っていた数値がコミット済みデータから再現しない**ので取り下げた。

| 仮説 | 結論 | 再現 |
|---|---|---|
| 隔年現象（上がった翌年は下がる） | 棄却 | **数値は再現せず** |
| 二次難易度→平均点の翻訳 | 断念（精度不足） | **数値は再現せず** |
| 志願倍率が最低点の70%を説明 | 成立 | ○ r=+0.837, R²=0.700, LOO MAE 1.04pt |
| 需要のパススルーが順位とともに減衰 | 検出力不足 | ○ `sd3.py` r=+0.05, p=0.52 |
| 得点開示から科目間相関 | データ不足 | ○（ただし件数が違う。下記） |

- **隔年現象**: 10年の得点率の1階差分の lag-1 自己相関は 実測 r=−0.441、iid 帰無の
  平均が r=−0.459。実測は帰無より負ですらなく、隔年現象の証拠はない（棄却は正しい）。
  旧 README の「実測 −0.568 / 帰無 −0.696 / p=0.992」は出てこない。帰無平均は系列長を
  n=5〜13 のどこに取っても −0.45〜−0.48 で、−0.696 にはならない。別の統計量か別の系列で、
  その入力が repo に無い。
- **難易度→平均点**: `data/dist.json` の17年で LOO MAE 4.76pt vs 変動SD 5.60pt、r=−0.306。
  予測になっていないので断念は正しい。旧 README の「11年OOS、MAE 6.65pt、σ 4.09pt」は
  どの11年窓を取ったかが記録されておらず一意に決まらない。
- **志願倍率**: 完全に再現する。ただし同時点の相関であって予測ではない。志願倍率が
  確定するのは出願締切後（令和9なら 2027-02-03）で、そこから対策は動かせない。
- **得点開示**: `kaiji2.json` は全11件だが**工学部はそのうち4件**。旧 README の
  「工学部分が11件」はファイル全体の行数。データ不足という結論は変わらない（むしろ強まる）。

## 既知の限界

1. **配点 regime の断層。** 共通テスト『情報Ⅰ』が入ったのは令和7年度入試（2025）から。
   8年パネルのうち現行配点は 2 年だけで、残り 6 年は満点 1000 点・情報Ⅰ無しの別制度。
   本分析は「情報Ⅰ が共テ分散の 48.4% を占める」と言いながら、最低点の分散 σ を
   情報Ⅰ が存在しない年から推定している。ただし共テは最低点分散の 12% しか占めないので、
   σ への影響は 10.3→10.6点（+3%）程度（`rb.py` 6.）。
2. **定員の断層。** 情報学科の受入学生数目安が 87人（令和6）→94人（令和9）。過去平均は使えない。
3. **`dv` のゼロ和制約。** 6 学科の系列は独立ではなく、F 検定の自由度は過大。
   `sd7.py` が出す cov<0 の一部は実質のない機械的副産物。
4. **分散シェアは全国分布の切断推定**であり、京大工受験層の同時分布ではない。
   科目間相関を推定できるデータ（得点開示 n=11）が足りない。
5. **`sT` / `muT` の出所不明。** §3 の確率の水準はこの 2 定数の関数。
   「ユーザー自身の模試成績は結論に使っていない」は §3 には当てはまらない。
6. **`dep.json` の `app` / `acc` の一次資料が無い。** `acc` は合格者数として使われているが
   募集要項の受入学生数目安と 1–2 人ずれる。定義が確定していない。
7. 設問別データは令和8年度の1年分のみ。項目の局所独立を仮定している。
8. **§6 の一部は再現しない。** 隔年現象と難易度→平均点の旧数値は入力が repo に無く、
   `rej.py` で計算し直した値に差し替えた。結論（棄却・断念）は両方とも変わらない。

## 再現方法

標準ライブラリのみ。numpy / scipy 不要。Python 3.11 で確認。

```bash
cd analysis
python3 build_dep.py  # dep.json が一次資料と一致することを検算
python3 rb.py         # 頑健性チェック（全結論の信頼度）
python3 sd5.py        # 学科順位・残差分散の並べ替え検定
python3 sd6.py        # 情報−各学科の最低点差（8年）
python3 sd7.py        # ギャップ分散分解と第2志望ラダー
python3 kt.py         # 共テ各科目のパーセンタイル表と京大工換算
python3 kt2.py        # 上位10%層内の分散シェア
python3 irt_run.py    # 設問単位の取りこぼし（要 ../data/q_r8.csv）
python3 rej.py        # §6 棄却・断念した仮説の再現
```
