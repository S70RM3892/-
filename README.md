# 京大工学部 情報学科 受験分析（令和9年度 / 2027年2月25・26日）

公開情報のみを一次資料から収集・検証した分析一式。

## 確定している制度事実（令和9年度 募集要項 r9.pdf より座標抽出・検算済み）

配点（縦計が 1025 に一致することを検算）

| 区分 | 国語 | 地歴公民 | 数学 | 理科 | 外国語 | 情報 | 計 |
|---|---|---|---|---|---|---|---|
| 共通テスト | 25 | 50 | 25 | 25 | 50 | 50 | 225 |
| 個別学力検査 | 100 | — | 250 | 250 | 200 | — | 800 |
| 計 | 125 | 50 | 275 | 275 | 250 | 50 | 1025 |

- 二次素点 650（国語100 / 数学200 / 理科200 / 英語150）→ 工学部配点 800
  （国語×1.0 / 数学×1.25 / 理科×1.25 / 英語×1.333）
- 二次時間割: 2/25 国語 9:30–11:00 (90分) / 数学 13:30–16:00 (150分)
  　　　　　　 2/26 英語 9:30–11:30 (120分) / 理科 13:30–16:30 (180分)
- 大問別配点は問題用紙に印刷される（数学 30/35/40点）
- 数学B＝数列のみ、数学C＝ベクトル・平面上の曲線と複素数平面のみ
- 第1段階選抜: 工学部全体で募集人員の約3.0倍、共テ1000点満点の別配点
  （国200/地公100/数200/理200/外200/情100）。10年で除外は7人（0.18%）
- 学科は第2志望まで選択可（ここまでが公式）

### 公式には確認できていない前提（以下の第2志望の分析はすべてこれに依存）

割り振りの手順について、公式の記載は「受入学生数を目安として学科別に合格者を決定」（募集要項）、
「成績及び志望順位に基づき合格者を決定」（選抜要項）だけで、アルゴリズムは明文化されていない。
本分析は **serial dictatorship**（学部全体を総点順に並べ、各人を第1志望→第2志望の順に空きのある
学科へ入れる）を仮定している。情報学科が8年連続で最低点1位という実績はこの仮定と矛盾しないが、
仮定を証明もしない。「第1志望者を先に確定し、残席に第2志望者を入れる」方式なら下の定理は成り立たない。

## 主要な分析結果

### 1. 第2志望の流れは一方向（serial dictatorship を仮定したときの定理）
c を第1志望として落ち d に第2志望で合格した人は、点数 < cutoff_c かつ 点数 ≥ cutoff_d。
よって **cutoff_c > cutoff_d**。流入は最低点の高い学科から低い学科へしか起こらない。

- 情報学科は 2019–2026 の8年すべてで最低点1位 → 仮定のもとで**流入ゼロ、定員は100%が第1志望者**
- 自分の第1志望より最低点が高い学科を第2志望に書いても、仮定のもとでは無効
- 第2志望は志願倍率ではなく最低点で選ぶ（建築は倍率2.12位／最低点3.62位で乖離）

### 2. 情報学科の合格最低点は6学科で突出して不安定
対象は絶対的な最低点ではなく **dv＝その年の6学科平均からの乖離**（試験難易度の年次変動は引いてある）。
絶対値の年変動はずっと大きい（情報の最低点得点率SD 4.2pt＝約43点/1025）が、難易度は受験者全員に
共通に効くので、合否に効くのは相対位置のほう。
トレンド除去残差SD: 情報 1.04pt（=10.6点/1025）、他5学科プール 0.49pt。
F = 4.45、残差の学科ラベル並べ替え検定 p = 0.0041（Bonferroni×6 で 0.025）。
下位学科は溢れた受験生が緩衝材になり学部全体プールで決まるため静か（地球工 0.25pt）。
弱点: n=8年。2024年を除くと情報のSDは 0.70pt まで落ちる（他の年を除いても 0.84–1.15）。
「情報は他学科より不安定」は残るが、10.6点という大きさは2024年の1点に強く依存している。

### 3. 第2志望ラダー（8年平均差・最低点ノイズ込み）
**下表の「合格確率」は絶対値として読めない。** `sd7.py` に「自分の位置＝情報最低点の 0.553σ 下
（σ=65.4点）」という仮置きがハードコードされており、29.0% はそこから出ているだけで公開データ由来ではない。
使えるのは第2志望どうしの相対比較（どの学科でどれだけ必要点が下がるか）まで。
8年平均差の標準誤差は 4–5点、2026年単年の差は平均より 6–14点小さい。

| 第2志望 | 8年平均差 | 差のSD | 合格確率（仮置き前提） |
|---|---|---|---|
| なし | — | — | 29.0% |
| 物理工 | 41.2点 | 14.7 | 53.0% |
| 電電 | 52.4点 | 12.8 | 59.6% |
| 建築 | 55.3点 | 14.8 | 61.2% |
| 地球工 | 72.3点 | 12.0 | 70.6% |
| 理工化 | 78.3点 | 12.7 | 73.6% |

ギャップ分散の 67–95% は情報学科自身の変動が占める
（＝第2志望は学部で唯一よく動く線を名指しでヘッジしている）。

### 4. 共通テストの実効配点
1素点あたりの価値: 情報Ⅰ・地歴公民 0.50点 / 英語 0.25点 / 国語・数学・理科 0.125点。
**共テ情報Ⅰの1点＝共テ数学の4点。**

情報Ⅰの比重 22.2% は京大7学部で最大（経済16.7 / 理10.0 / 農8.6 / 医9.1 / 薬9.1 / 教育5.7）。
工学部だけが「二次で出る科目の共テを半額、出ない科目を定価」にしている（理学部はその真逆）。

全国上位10%→上位1% の価値（1025点換算、令和8/令和7）:
情報Ⅰ 7.0/4.0、地歴公民 4.0–4.5/4.5–6.0 に対し、
**数ⅠA+数ⅡBC+物理+化学の4科目合計が 6.9/6.8**。

上位10%層内の分散シェア（地歴公民＝地理）: 情報Ⅰ+地歴公民 = 68.0%/66.8%（配点シェア44.4%）、
理系4科目 = 11.7%/12.8%（配点22.2%）。切断なしの全国SDでも 57.7%。

情報Ⅰは全国平均が 69.26（令和7）→ 56.59（令和8）と −12.7点。全科目中で最大の振れ。

### 5. 共テで京大工レベルがまだ落としている点（設問単位）

大学入試センター公表の「設問別得点状況」(`data/q_r8.csv`) に、全設問共通の
ディスクリミネーション r を持つ正規オジャイブ模型を当て、r は模型の総得点SDが
公表SDに一致するよう較正した（平均は構成上厳密一致、p90は誤差2–4点、
p97.7は2–5点で追随）。

全科目で全国上位2.3%(z=+2)相当の受験生が、共テでまだ落としている点（1025点換算）:

| 科目 | 模型 | 公表分位点から直接 |
|---|---|---|
| 情報Ⅰ | 8.4点 | 6.0点 |
| 地歴公民（地理） | 6.7 | 6.0 |
| 国語 | 3.8 | 2.9 |
| 英語リスニング | 3.7 | 2.5 |
| 物理 | 2.4 | 1.9 |
| 数学ⅠA | 2.1 | 1.8 |
| 数学ⅡBC | 0.9 | 0.5 |
| 化学 | 0.8 | 0.5 |
| 英語リーディング | 0.8 | 0.5 |
| **合計** | **29.5** | **22.5** |

情報Ⅰ＋地歴公民が 51–53%、理系4科目（数ⅠA・数ⅡBC・物理・化学）は 21%。
地歴公民は受験科目の地理で計算している（以前の版は政経で、得点設計票の地理と食い違っていた）。
（以前の版は国語を集計から落としていた。）
合計 22.5–29.5点は情報学科の最低点の相対変動σ(10.6点)の 2.1–2.8 倍にあたる。

設問単位では、情報Ⅰの取りこぼしは上位10設問で58%、大問別では
第1問34% / 第2問28% / 第3問22% / 第4問16%（令和8年度）。
理系科目の中では物理・数学ⅠAの取りこぼしが化学・数学ⅡBCの3–4倍。

この節の限界（結論を使う前に読むこと）:
- 模型は上位側を系統的に過小評価する（p97.7を100点科目で2–5点、国語で8点下回る）。よって模型側の
  数字は過大。ただし2つの数字は「上限と下限」ではない。どちらも**科目ごとの全国上位2.3%**という
  同じ恣意的な基準を別の方法で読んだだけ。
- 「z=+2＝京大工レベル」に実測の裏付けはない。京大工志望者の共テ科目別分布は公開されておらず、
  ここは予備校の志望者別統計（共テ模試の志望別成績分布など）で置き換えるべき箇所。
- 測っているのは「落としている点」であって「取り返しやすい点」ではない。時間あたりの回収率は
  このデータからは出ない。二次（800点）との比較もしていない。
- 設問データは令和8年度の1年分のみ。情報Ⅰは平均が前年から −12.7点動いた年である。

### 6. 棄却・断念した仮説、および参考
- 隔年現象: 棄却（実測 r=−0.568 に対し比率バイアスの帰無で r=−0.696、p=0.992）
- 難易度→平均点の翻訳: 不可能（11年OOSで MAE 6.65pt > 変動σ 4.09pt）
- （棄却ではなく参考）志願倍率が最低点の70%を説明（年固定効果48観測、r=+0.837、LOO MAE 1.03pt）。
  ただし大半は学科間の恒常的な差。学科固定効果も入れた学科内の年次変動では傾きの符号すら揃わない（`sd3.py`）
- 需要のパススルーが最低点順位とともに減衰: 検出力不足で検証不能（r=+0.05, p=0.52）
- 得点開示データ: 工学部分が11件しかなく科目間相関の推定に使えない

## 再現方法

```bash
cd analysis
python3 sd5.py   # 学科順位・残差分散の並べ替え検定
python3 sd6.py   # 情報−各学科の最低点差（8年）
python3 sd7.py   # ギャップ分散分解と第2志望ラダー
python3 kt.py    # 共テ各科目のパーセンタイル表と京大工換算
python3 kt2.py   # 上位10%層内の分散シェア
python3 irt_run.py # 設問単位の取りこぼし（要 ../data/q_r8.csv）
```

## 注意
- 分散シェアは全国分布の切断推定であり、京大工受験層の同時分布ではない
- `analysis/` の結論はユーザー自身の模試成績を使っていない（第2志望ラダーの仮置き位置を除く）。
  `artifacts/` の得点設計票・出題地図は模試成績を使っている
- 合格者の最高点・最低点・平均点（総点）は京大公式の「一般選抜諸統計」の値。科目別内訳は非公表
