# 京大工学部 情報学科 受験分析（令和9年度 / 2027年2月25・26日）

公開情報のみを一次資料から収集・検証した分析一式。

## 確定している制度事実（令和9年度 募集要項 r9.pdf より座標抽出・検算済み）

配点（縦計が 1025 に一致することを検算）

| 区分 | 国語 | 地歴公民 | 数学 | 理科 | 外国語 | 情報 | 計 |
|---|---|---|---|---|---|---|---|
| 共通テスト | 25 | 50 | 25 | 25 | 50 | 50 | 225 |
| 個別学力検査 | 100 | — | 250 | 250 | 200 | — | 800 |
| 計 | 125 | 50 | 275 | 275 | 250 | 50 | 1025 |

- 二次素点 650（国語100 / 数学200 / 理科200 / 英語150）→ 工学部配点 800
  （国語×1.0 / 数学×1.25 / 理科×1.25 / 英語×1.333）
- 二次時間割: 2/25 国語 9:30–11:00 (90分) / 数学 13:30–16:00 (150分)
  　　　　　　 2/26 英語 9:30–11:30 (120分) / 理科 13:30–16:30 (180分)
- 大問別配点は問題用紙に印刷される（数学 30/35/40点）
- 数学B＝数列のみ、数学C＝ベクトル・平面上の曲線と複素数平面のみ
- 第1段階選抜: 工学部全体で募集人員の約3.0倍、共テ1000点満点の別配点
  （国200/地公100/数200/理200/外200/情100）。10年で除外は7人（0.18%）
- 学科は第2志望まで選択可。割り振りは serial dictatorship
  （第1・第2志望を問わず学部全体を点数順に並べ、各学科の定員まで取る）

## 主要な分析結果

### 1. 第2志望の流れは一方向（定理）
c を第1志望として落ち d に第2志望で合格した人は、点数 < cutoff_c かつ 点数 ≥ cutoff_d。
よって **cutoff_c > cutoff_d**。流入は最低点の高い学科から低い学科へしか起こらない。

- 情報学科は 2019–2026 の8年すべてで最低点1位 → **流入ゼロ、定員は100%が第1志望者**
- 自分の第1志望より最低点が高い学科を第2志望に書いても物理的に無効
- 第2志望は志願倍率ではなく最低点で選ぶ（建築は倍率2.12位／最低点3.62位で乖離）

### 2. 情報学科の合格最低点は6学科で突出して不安定
トレンド除去残差SD: 情報 1.04pt（=10.6点/1025）、他5学科プール 0.49pt。
F = 4.45、残差の学科ラベル並べ替え検定 p = 0.0041（Bonferroni×6 で 0.025）。
下位学科は溢れた受験生が緩衝材になり学部全体プールで決まるため静か（地球工 0.25pt）。

### 3. 第2志望ラダー（8年平均差・最低点ノイズ込み）
| 第2志望 | 8年平均差 | 差のSD | 合格確率 |
|---|---|---|---|
| なし | — | — | 29.0% |
| 物理工 | 41.2点 | 14.7 | 53.0% |
| 電電 | 52.4点 | 12.8 | 59.6% |
| 建築 | 55.3点 | 14.8 | 61.2% |
| 地球工 | 72.3点 | 12.0 | 70.6% |
| 理工化 | 78.3点 | 12.7 | 73.6% |

ギャップ分散の 67–95% は情報学科自身の変動が占める
（＝第2志望は学部で唯一よく動く線を名指しでヘッジしている）。

### 4. 共通テストの実効配点
1素点あたりの価値: 情報Ⅰ・地歴公民 0.50点 / 英語 0.25点 / 国語・数学・理科 0.125点。
**共テ情報Ⅰの1点＝共テ数学の4点。**

情報Ⅰの比重 22.2% は京大7学部で最大（経済16.7 / 理10.0 / 農8.6 / 医9.1 / 薬9.1 / 教育5.7）。
工学部だけが「二次で出る科目の共テを半額、出ない科目を定価」にしている（理学部はその真逆）。

全国上位10%→上位1% の価値（1025点換算、令和8/令和7）:
情報Ⅰ 7.0/4.0、地歴公民 4.0–4.5/4.5–6.0 に対し、
**数ⅠA+数ⅡBC+物理+化学の4科目合計が 6.9/6.8**。

上位10%層内の分散シェア: 情報Ⅰ+地歴公民 = 66.6%/62.2%（配点シェア44.4%）、
理系4科目 = 12.3%/14.6%（配点22.2%）。切断なしの全国SDでも 57.7%。

情報Ⅰは全国平均が 69.26（令和7）→ 56.59（令和8）と −12.7点。全科目中で最大の振れ。

### 5. 共テで京大工レベルがまだ落としている点（設問単位）

大学入試センター公表の「設問別得点状況」(`data/q_r8.csv`) に、全設問共通の
ディスクリミネーション r を持つ正規オジャイブ模型を当て、r は模型の総得点SDが
公表SDに一致するよう較正した（平均は構成上厳密一致、p90は誤差2–4点、
p97.7は2–5点で追随）。

全科目で全国上位2.3%(z=+2)相当の受験生が、共テでまだ落としている点（1025点換算）:

| 科目 | 模型 | 公表分位点から直接 |
|---|---|---|
| 情報Ⅰ | 8.4点 | 6.0点 |
| 地歴公民（政経） | 4.7 | 3.0 |
| 英語リスニング | 3.7 | 2.5 |
| 物理 | 2.4 | 1.9 |
| 数学ⅠA | 2.1 | 1.8 |
| 数学ⅡBC | 0.9 | 0.5 |
| 化学 | 0.8 | 0.5 |
| 英語リーディング | 0.8 | 0.5 |
| **合計** | **23.7** | **16.6** |

情報Ⅰ＋地歴公民が 54–55%、理系4科目（数ⅠA・数ⅡBC・物理・化学）は 26–28%。
合計 16.6–23.7点は情報学科の合格最低点の年変動σ(10.6点)の 1.6–2.2 倍にあたる。

設問単位では、情報Ⅰの取りこぼしは上位10設問で58%、大問別では
第1問34% / 第2問28% / 第3問22% / 第4問16%（令和8年度）。
理系科目の中では物理・数学ⅠAの取りこぼしが化学・数学ⅡBCの3–4倍。

模型は上位側を過小評価する（全科目でp97.7を2–5点下回る）ため、模型側の
23.7点は上限、公表分位点側の16.6点が下限。設問データは令和8年度の1年分のみ。

### 5. 棄却・断念した仮説
- 隔年現象: 棄却（実測 r=−0.568 に対し比率バイアスの帰無で r=−0.696、p=0.992）
- 難易度→平均点の翻訳: 不可能（11年OOSで MAE 6.65pt > 変動σ 4.09pt）
- 志願倍率が最低点の70%を説明（年固定効果48観測、r=+0.837、LOO MAE 1.03pt）
- 需要のパススルーが最低点順位とともに減衰: 検出力不足で検証不能（r=+0.05, p=0.52）
- 得点開示データ: 工学部分が11件しかなく科目間相関の推定に使えない

## ディレクトリ構成

```
analysis/   解析スクリプトと、それが読むデータ（相対パスで完結。そのまま python3 sd5.py で動く）
  sd.py–sd7.py    学科パネル分析（順位・残差分散・パススルー・第2志望ラダー）

  irt.py irt_run.py 設問別得点状況から項目反応模型を較正し、京大工レベルの取りこぼしを設問単位で算出

  dist_r6/7/8.csv 大学入試センター 科目別成績分布（全国・本試験）

artifacts/  公開済みアーティファクトのHTML
  kyodai-score-sheet.html  得点設計票（設計/記録/演習）

data/       一次資料
  r9.txt              令和9年度 募集要項（配点表の抽出元）
  r6senbatsu.txt      令和6年度 選抜要項
  r7haiten.txt        配点資料
```

## 再現方法

```bash
cd analysis
python3 sd5.py   # 学科順位・残差分散の並べ替え検定
python3 sd6.py   # 情報−各学科の最低点差（8年）
python3 sd7.py   # ギャップ分散分解と第2志望ラダー
python3 kt.py    # 共テ各科目のパーセンタイル表と京大工換算
python3 kt2.py   # 上位10%層内の分散シェア
python3 irt_run.py # 設問単位の取りこぼし（要 ../data/q_r8.csv）
```

## 注意
- 分散シェアは全国分布の切断推定であり、京大工受験層の同時分布ではない
- ユーザー自身の模試成績は本分析の結論には使っていない（公開情報のみ）
