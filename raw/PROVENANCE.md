# 資料の出所と権利

旧版はここが完全に空白だった。`raw/` に80近いスクレイプ済み HTML/JS が
`bn_356.html` `yz7.html` のような名前で置かれ、どこから取ったのか、
いつ取ったのか、再配布してよいのかが誰にも分からない状態だった。
README は冒頭で「公開情報のみを一次資料から収集・検証」と書いていたが、
実際には個人ブログ（note）や予備校の資料が混ざっていた。

## 分類

### A. 一次資料（大学・大学入試センターの公表物）

| ファイル | 内容 | 出所 |
|---|---|---|
| `data/r9.txt` | 令和9年度 京都大学 一般選抜 学生募集要項（テキスト抽出） | 京都大学 公式サイト |
| `data/r6senbatsu.txt` | 令和6年度 選抜要項 | 京都大学 公式サイト |
| `data/r7haiten.txt` | 配点資料 | 京都大学 公式サイト |
| `analysis/dist_r6.csv` `dist_r7.csv` `dist_r8.csv` | 科目別成績分布（全国・本試験） | 大学入試センター |
| `data/q_r8.csv` | 令和8年度 設問別得点状況 | 大学入試センター |
| `data/kyodai_official.json` | 学部別配点と合格最低点 | 京都大学 公表の入試状況 |

引用・分析目的での利用。数値そのものに著作権は及ばないが、
**PDF やページの丸ごと再配布は避けること。**

抽出元 PDF（`r9.pdf` 等）は、旧 `.gitignore` が `*.pdf` を除外していたため
リポジトリに存在しない。監査の連鎖を復元するには、募集要項 PDF を
京都大学公式サイトから再取得し、取得日と URL をこの表に追記すること。

`p10_validate.py` が検出する。集計に入れてはならない。

## 公開前チェックリスト

このリポジトリを公開（public 化）する前に:

1. [ ] `raw/` の第三者ページ保存を削除する。
       解析コードは `raw/` を一切読まないので、消しても結果は変わらない。
       `bash scripts/strip_thirdparty.sh` で実行できる。
2. [ ] `data/zk/`（Z会）と `data/toshin.json`（東進）を削除するか、
       取得スクリプトだけ残して生成物を落とす。
3. [ ] `data/kaiji*.json` に個人が特定できる情報が無いことを確認する。
4. [ ] `git log` と `git show` で、過去のコミットに同じものが残っていないか確認する
       （履歴に残る。必要なら filter-repo で除去）。
5. [ ] 上記 A の一次資料も、丸ごとの再配布ではなく取得手順の記載に置き換えることを検討する。

削除しても `analysis/` の全スクリプトは動く。依存しているのは
`analysis/dep.json`, `analysis/dist_r*.csv`, `data/q_r8.csv`,
`data/kyodai_official.json`, `data/dist.json`, `data/kaiji*.json`,
`data/r9.txt`（引用のみ）だけである。
